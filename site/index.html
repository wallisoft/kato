How it works

1

Install on each computer

A normal installer on Windows, one command on Linux. AirShare lives quietly in your tray.

2

Give them the same passphrase

Click Generate on one computer and type the same words on the others. They find each other on your network by themselves.

3

Drag them into place

Arrange your computers on a simple grid to match your desk. Set it up on any one of them, and the others follow.

Features

Any side, any mix

Left, right, above or below, in a grid of up to nine computers. Windows and Linux in any combination.

Private by design

Computers connect directly over encrypted TLS 1.3 and only trust each other. Other people on the same Wi-Fi can't join in.

No master computer

Use whichever keyboard is nearest. Every computer can drive its neighbours, and nothing stops working if one is switched off.

Safe by default

Press Esc three times to bring your pointer home. If a computer sleeps, locks or disconnects, control comes straight back to you.

Clipboard included

Built on Clickboard, so copy and paste text, images and files between computers too.

Wayland and macOS Coming

Modern Linux desktops on Wayland are next, then Mac.

Good to know

One main computer

Choose the computer whose keyboard and mouse you use. It drives the others; they need no keyboard or mouse of their own. Change it any time in Layout.

Windows without a mouse

Windows hides the pointer on computers that have no mouse attached. If a Windows computer in your layout has no mouse of its own, leave any cheap USB mouse plugged in.

Lock screens and security prompts

Windows protects its lock screen and "Do you want to allow…" prompts from being controlled remotely. AirShare respects that: control comes straight back to your main computer, and you answer the prompt there.

Windows that run as administrator

Windows also keeps ordinary programs out of apps running as administrator. If you need AirShare to control those, tick the administrator windows option when you install. It's off by default.

Linux on X11

AirShare works with Linux desktops running X11 today. Wayland support is on its way.

Your firewall

The installers open AirShare's ports (TCP 47810 and UDP 47812) on private networks only. Your computers talk directly to each other, never through our servers.

Download

Windows 10 and 11

Download for Windows

Run AirShare-Setup.exe and follow the steps. Windows may say "Windows protected your PC" until our Microsoft Store listing arrives: click More info, then Run anyway.

Linux (Ubuntu 22.04+ and similar, X11 session, in a terminal)

curl -fsSL https://github.com/wallisoft/airshare-releases/releases/latest/download/install.sh | bash

Installs into your home folder. It asks for your password only to add two small system libraries and open AirShare's ports if your firewall is on.
